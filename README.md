# Menuiserie web

السيت تاع الورشة: Astro + Three.js + GSAP ScrollTrigger + Lenis.

## التشغيل
```
npm install
npm run dev      # http://localhost:4321
npm run build    # النسخة النهائية في dist/
```

## الصفحة الرئيسية
1. **قصة البناء** (`src/components/BuildSequence.astro` + `src/scripts/build-sequence/`)
   - `index.js`: التايملاين المربوط بالسكرول (6 فصول: المخطط، الخشب الخام، القص، التركيب، الصباغة، فتح الصندوق) + العداد.
   - `model.js`: موديل السرير مبني بالكود. أسماء القطع (headboard, footboard, side-rail-*, box-bottom, traverse, lift-frame, slat, gas-piston, screw) هي نفسها اللي لازم تكون في ملف GLB من Blender كي نبدلوه.
   - `materials.js`: مواد الخشب + مسحة الصباغة (shader).
   - `particles.js`: نشارة القص + الغبرة في الضو.
   - `extras.js`: الخزانة، الطاولة الجانبية، الكوموضة، والكاميو.
   - `map3d.js`: خريطة الجزائر 3D (تضاريس بيضاء، 69 أسطوانة صفراء مضيئة، طريق يترسم، كاميو يمشي عليه، بوتيك الورشة، وpills بالمدن والمسافة). الكاميرا: نظرة عامة ← تتبع الكاميو ← زوم على الورشة.
   - `mapdata.js`: حدود الجزائر والطريق ومحطاتو (مستخرجة من الـ SVG القديم). `wilayas.js`: الولايات الـ 69 بإحداثيات تقريبية.
   - الخريطة تتبنى وقت الفراغ (`requestIdleCallback`). إذا فشلت لأي سبب، السيت يكمل بلا خريطة ما يوقفش.
   - `worker.js`: النجار (دمية خشب) يمشي، يضرب بالمطرقة، ويصبغ بالفرشاة.
   - اليد بالقلم في المخطط: تكتب الترحيب وحدها، ومن بعد تتبع الخطوط كي يترسمو.
   - المخطط بالقلم: SVG في `BuildSequence.astro`.
2. **شريط المنتوجات** (`ProductsBar.astro`): يتحرك بالسكرول في الديسكتوب، بالسحب في التيليفون. البيانات في `src/data/products.json`.
3. **أنواع الخشب** (`Woods.astro`) و**صور الورشة** (`Workshop.astro`).

## الخطة البديلة
إذا التيليفون ما يدعمش WebGL، ولا ذاكرته ضعيفة، ولا المستعمل مقفل الحركات: يبان المخطط والفصول كنص عادي بلا 3D.

## الطلبات والأدمن
- الموقع دوك `hybrid` (Astro + `@astrojs/node`): يحتاج سيرفر Node (VPS مثلا)، ماشي استضافة ثابتة.
- تشغيل: `npm run build && node dist/server/entry.mjs` (PORT و HOST من المتغيرات).
- الطلبات والحساب يتخزنو في `data/` (orders.json, admin.json). **خذ نسخة احتياطية منو.** تنجم تبدل المجلد بـ `DATA_DIR`.
- الأدمن: `/admin` — الدخول الافتراضي `admin` / `admin`. بدّلو من أسفل الصفحة (تغيير اسم المستخدم وكلمة السر) قبل ما يطلع السيت.
- الزبون: يضغط على منتوج ← `/produits/<slug>` ← يملأ الفورم ← `/commande/<رقم>` فيها زر «تحميل ملف الطلب».
- الأدمن فيه 3 أقسام: **الطلبات** (مع إحصائيات المنتوجات والأكثر مبيعا)، **المنتوجات** (زيادة، تعديل، ثمن، صورة، متوفر/غير متوفر، حذف)، **التعليقات** (حذف).
- المنتوجات تتخزن في `data/products.json` (تبدأ من `src/data/products.json`)، والصور المرفوعة في `data/uploads/`، والتعليقات في `data/reviews.json`.
- **الزيارات** (`/admin/stats`): إحصائيات داخلية بلا جوجل أناليتيك وبلا كوكيز (زوار، مشاهدات، مصدر الزيارة، الجهاز، ضغطات واتساب/اتصال، مسار الزيارة ← الطلب). تخزن في `data/analytics.jsonl`.
- **ماسنجر** (`/admin/meta`): ربط صفحة الفيسبوك. Webhook: `https://دومينك/api/meta/webhook`. الرسائل تجي لصندوق في الأدمن، تنجم ترد وتحوّل المحادثة لطلب. التوكنات في `data/meta.json` (لا تشاركه).

# Menuiserie web

السيت تاع الورشة: Astro + Three.js + GSAP ScrollTrigger + Lenis.

## التشغيل
```
npm install
npm run dev      # http://localhost:4321
npm run build    # النسخة النهائية في dist/
```

## الصفحة الرئيسية
1. **قصة البناء** (`src/components/BuildSequence.astro` + `src/scripts/build-sequence/`)
   - `index.js`: التايملاين المربوط بالسكرول (6 فصول: المخطط، الخشب الخام، القص، التركيب، الصباغة، فتح الصندوق) + العداد.
   - `model.js`: موديل السرير مبني بالكود. أسماء القطع (headboard, footboard, side-rail-*, box-bottom, traverse, lift-frame, slat, gas-piston, screw) هي نفسها اللي لازم تكون في ملف GLB من Blender كي نبدلوه.
   - `materials.js`: مواد الخشب + مسحة الصباغة (shader).
   - `particles.js`: نشارة القص + الغبرة في الضو.
   - `extras.js`: الخزانة، الطاولة الجانبية، الكوموضة، والكاميو.
   - `map3d.js`: خريطة الجزائر 3D (تضاريس بيضاء، 69 أسطوانة صفراء مضيئة، طريق يترسم، كاميو يمشي عليه، بوتيك الورشة، وpills بالمدن والمسافة). الكاميرا: نظرة عامة ← تتبع الكاميو ← زوم على الورشة.
   - `mapdata.js`: حدود الجزائر والطريق ومحطاتو (مستخرجة من الـ SVG القديم). `wilayas.js`: الولايات الـ 69 بإحداثيات تقريبية.
   - الخريطة تتبنى وقت الفراغ (`requestIdleCallback`). إذا فشلت لأي سبب، السيت يكمل بلا خريطة ما يوقفش.
   - `worker.js`: النجار (دمية خشب) يمشي، يضرب بالمطرقة، ويصبغ بالفرشاة.
   - اليد بالقلم في المخطط: تكتب الترحيب وحدها، ومن بعد تتبع الخطوط كي يترسمو.
   - المخطط بالقلم: SVG في `BuildSequence.astro`.
2. **شريط المنتوجات** (`ProductsBar.astro`): يتحرك بالسكرول في الديسكتوب، بالسحب في التيليفون. البيانات في `src/data/products.json`.
3. **ركّب سريرك** (`src/components/Configurator.astro` + `src/scripts/configurator/`)
   - الزبون يختار المقاس (90/140/160)، صندوق نعم/لا، واللون (مصبوغ/طبيعي)، والسرير 3D يتبدل قدامو. زر «افتح الصندوق» يحل القاعدة. السحب يدور السرير (والسكرول العمودي يبقى يخدم في التيليفون).
   - **كل الأرقام في ملف واحد: `src/data/configurator.json`**: المقاسات، الأسعار (`null` = «نأكدوه معاك»)، زيادة الصباغة `paintExtra`، وسلاگ المنتوج اللي يتفتح فورمو لكل اختيار. السلاگ إذا ما كانش موجود ولا غير متوفر في الأدمين، السيت يرجع لأول منتوج متوفر.
   - `bed.js`: موديل السرير بمقاس متغير. `index.js`: الاختيارات والسعر والرابط والـ3D (يرسم غير ملي يكون القسم باين).
   - «اطلب هذا» يفتح `/produits/<slug>?sel=...`: الصفحة تبين الاختيار والملاحظة في الفورم تتعمر بيه، بلا تبديل في الباك.
   - إذا التيليفون ما يدعمش WebGL ولا ذاكرته ضعيفة: تبان صورة السرير بدل الـ3D، والاختيارات والطلب يخدمو عادي.
4. **أنواع الخشب** (`Woods.astro`) و**صور الورشة** (`Workshop.astro`).

## الخطة البديلة
إذا التيليفون ما يدعمش WebGL، ولا ذاكرته ضعيفة، ولا المستعمل مقفل الحركات: يبان المخطط والفصول كنص عادي بلا 3D.

## الطلبات والأدمن
- الموقع دوك `hybrid` (Astro + `@astrojs/node`): يحتاج سيرفر Node (VPS مثلا)، ماشي استضافة ثابتة.
- تشغيل: `npm run build && node dist/server/entry.mjs` (PORT و HOST من المتغيرات).
- الطلبات والحساب يتخزنو في `data/` (orders.json, admin.json). **خذ نسخة احتياطية منو.** تنجم تبدل المجلد بـ `DATA_DIR`.
- الأدمن: `/admin` — الدخول الافتراضي `admin` / `admin`. بدّلو من أسفل الصفحة (تغيير اسم المستخدم وكلمة السر) قبل ما يطلع السيت.
- الزبون: يضغط على منتوج ← `/produits/<slug>` ← يملأ الفورم ← `/commande/<رقم>` فيها زر «تحميل ملف الطلب».
- الأدمن فيه 3 أقسام: **الطلبات** (مع إحصائيات المنتوجات والأكثر مبيعا)، **المنتوجات** (زيادة، تعديل، ثمن، صورة، متوفر/غير متوفر، حذف)، **التعليقات** (حذف).
- المنتوجات تتخزن في `data/products.json` (تبدأ من `src/data/products.json`)، والصور المرفوعة في `data/uploads/`، والتعليقات في `data/reviews.json`.
- **الزيارات** (`/admin/stats`): إحصائيات داخلية بلا جوجل أناليتيك وبلا كوكيز (زوار، مشاهدات، مصدر الزيارة، الجهاز، ضغطات واتساب/اتصال، مسار الزيارة ← الطلب). تخزن في `data/analytics.jsonl`.
- **ماسنجر** (`/admin/meta`): ربط صفحة الفيسبوك. Webhook: `https://دومينك/api/meta/webhook`. الرسائل تجي لصندوق في الأدمن، تنجم ترد وتحوّل المحادثة لطلب. التوكنات في `data/meta.json` (لا تشاركه).

## قسم «من الخشب الخام لسريرك» (`src/components/BeforeAfter.astro`)
- مشهد سكرول: الخشب الخام يتفكّ في 8 ألواح (GSAP + ScrollTrigger مع pin) ويبان سرير جاهز. ملي يكمّل، تبان دوايرالألوان (02 وردي، 04 وردي بالأزرار، 07 رمادي، 14 أزرق، 17 أزرق بالأزرار، 08 بيج) والتبديل بينهم بنفس حركة الألواح.
- الألوان والأرقام والصور في مصفوفة `variants` فوق الملف. زر «اطلب هذا» يبان غير إذا المنتوج موجود في الكاتالوغ.
- مع `prefers-reduced-motion`: بلا أنيميشن، السرير ظاهر والتبديل فوري.

## القصة: 3 سكرولات (`BuildSequence.astro` + `scripts/build-sequence/index.js`)
- 1) المخطط ← السرير مركّب ومصبوغ. 2) «وماشي غير السرير» (خزانات وطاولات). 3) الكاميو و«نوصلو وين ما بغيت». كل سحبة تدخل فصل كامل (snap)، والسحبة الرابعة تدخل للمنتوجات.
- اختيار الخشب والقص وفتح الصندوق وأرقام الورشة تحذفو من القصة (المقاطع تمر كقطعة سريعة)، والباقي بسرعتو القديمة. التوقيتات في `PT`/`PF` والتوقف في `stops` داخل `index.js`.
- الأرقام المؤقتة (3800 زبون...) ما بقاتش تبان في القصة. «2 إلى 6 أيام» حذفتها من القصة، بصح `stats.json` مازال يستعملها في قسم الثقة.

## الهيرو (3 سكرولات) — الحملة تاع الأسبوع
- `src/config/heroCampaign.ts`: كل الصور والنصوص (عربي + فرنسي). باش تبدل المنتوج تاع الأسبوع بدل غير هذا الملف.
- `src/components/Hero.astro`: الهيكل والـ CSS.
- `src/scripts/hero3d.js`: الأنيميشن 3D (Three.js + GSAP ScrollTrigger، pin على 300vh، scrub 0.6، snap كل 1/3): لوح ← سرير ← خزانة + طاولة جانبية ← الكاميو.
- `src/scripts/hero.js`: نسخة بالصور (من config) للتيليفونات اللي ما يقدروش على 3D. ولي مقفل الحركات يشوف الصور ثابتين.
- المراحل: لوح خشب ← (1) المنتوج + العنوان ← (2) القطع المكملة حواليه ← (3) الكاميو + "نوصّلو وين ما بغيت" ← المنتوجات (#produits).
- `src/components/BuildSequence.astro` والـ scripts تاعو (`src/scripts/build-sequence/`) مازالو في المشروع بصح ما راهمش مستعملين.
